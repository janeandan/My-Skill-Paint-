# 🐶 Animal to Crayon Stickers 🖍️

**Turn animal photos into consistent, expressive chibi crayon stickers.**

Transform animal photographs or existing animal illustrations into lively, cute, character-consistent reaction stickers in a colorful crayon illustration style.

This is a character-design and visual-storytelling skill, not a photo filter. The goal is not merely to add clothes, captions, or texture to a photograph. First, establish a recognizable chibi character; then, express emotions and design the context.

> **Core Principle:** Preserve identity, perform the emotion, design the context, and unify the medium.

## ✨ Features

- **Character Consistency**: Creates recognizable chibi characters from real animals.
- **Expressive Reactions**: Generates cute, wordless reactions or daily-life scenes.
- **Contextual Styling**: Adds appropriate colors and outfits based on the context.
- **High-Quality Output**: Proposes independent square PNG stickers (approx. 1024 x 1024) with transparent outer boundaries.
